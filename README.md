# Övningar - OOP Grund + Github

I den här uppgiften har jag lärt mig att använda grunderna i OOP och föra över arbetet till GitHub. De fyra principerna är:

Encapsulation (inkapsling): Inkapsling innebär att detaljer om hur ett objekts data hanteras döljs, så att datan bara kan nås och ändras på ett kontrollerat sätt.

Inheritance (arv): Arv gör det möjligt för en klass att ärva attribut och metoder från en annan klass. Då slipper jag skriva samma kod flera gånger, och det blir enklare att hålla koden ren och överskådlig.

Polymorphism (polymorfism): Polymorfism innebär att olika klasser kan ha metoder med samma namn men olika implementationer. Samma metodanrop kan alltså ge olika resultat beroende på vilken klass objektet tillhör.

Abstraction (abstraktion): Abstraktion innebär att komplexa detaljer döljs för användaren, så att endast de funktionella delarna av ett objekt visas.
